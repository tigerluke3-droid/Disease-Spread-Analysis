# Disease Spread Analysis

A Python-based simulation project exploring how infectious diseases spread through a population using the **SIR (Susceptible, Infectious, Recovered) model** and **Monte Carlo simulations**.

## About the Project

This project was completed as part of my **Introduction to Computer Science** course at Denison University (CS-111). It was a **two-person group project**, developed collaboratively with one other student.

The goal of the project was to apply introductory Python programming and data analysis concepts to model the spread of an infectious disease. We examined how changes in population, transmission, and recovery rates affected infection patterns and overall epidemic trajectories.

## What We Did

- Developed a Python implementation of the **SIR disease-spread model**.
- Analyzed how population size, transmission rates, and recovery rates affected infection peaks and epidemic trajectories.
- Ran **100 Monte Carlo simulations** to compare randomized outcomes with expected SIR behavior and examine variability between simulations.
- Visualized changes in **susceptible, infectious, and recovered populations over time** using Python and Matplotlib.
- Worked collaboratively throughout the development, testing, analysis, and interpretation of the project.
